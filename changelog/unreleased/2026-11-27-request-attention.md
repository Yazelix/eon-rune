- **`WindowHandle::request_attention()`: an attention request that makes no focus, raise or restore call.** macOS asks for one Dock bounce (`NSInformationalRequest`; AppKit ignores it while the app is active), Windows flashes the taskbar, X11 sets the urgency hint, and Wayland activates the window's own surface without a launcher token, waiting as `App::attention_wait` says (the compositor decides whether that marks it urgent). Unlike `WindowHandle::focus`, it never unminimizes the window or calls `focus_window`; it runs in order with the handle's other requests, and hidden, closed or GPU-failed windows ignore it. Headless runs ignore it.
